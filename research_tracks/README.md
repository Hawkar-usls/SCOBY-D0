# SCOBY-D0 research tracks

This directory integrates the canonical SCOBY research inventory from `Hawkar-usls/janus-meta-registry/data/SCOBY-UNIVERSAL-RESEARCH-GUIDE-2026-08-20-v1.0.json` without silently creating a second evidence authority.

`janus-meta-registry` remains the canonical provenance store. Each `TRACK.json` here is a navigation bridge: every source artifact is assigned to one or more SCOBY-D0 research tracks while preserving its canonical path and claim boundary.

## Tracks

- `SKINGPT_SENSOR_SKIN` — BC-derived tactile/thermal sensor-skin research.
- `SCOBY_D0_C2_EVIDENCE` — legacy C2/acetate/context evidence lineage.
- `SCOBY_D1_COMPOSITES` — chitin, electrosynthesis, baseline structures and matrix engineering.
- `CARBON_MATERIALS` — treated/thermal black-residue and carbon-material characterization lane.
- `OIL_SORPTION_ENVIRONMENT` — oil/water selectivity, marine pads and retrievable boom.
- `CHITIN_VIBRISSA` — chitin reinforcement and identity-gated vibrissa/biotube questions.
- `TIO2_COMPATIBILITY` — TiO2 during BC formation versus post-harvest BC-TiO2 composites.
- `EXTERNAL_REVIEW_OUTREACH` — correspondence and external-validation infrastructure.
- `SEPARATE_SPECULATIVE_BRANCH` — isolated speculative hypotheses that must not contaminate empirical tracks.

## Promotion invariant

Observation → hypothesis → preregistered screen → controlled replicated result → instrument-characterized result → independent/external validation → application-specific validation.

A navigation bridge is not evidence, correspondence is not validation, and a hash is integrity rather than truth.
